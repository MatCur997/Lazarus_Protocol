LAZARUS - cartella di presentazione (backend + interfaccia)

Requisiti: uv e Ollama avviato. Modelli: ollama pull gemma4:12b  e  ollama pull bge-m3
Avvio: doppio clic su avvia_interfaccia.bat  ->  http://127.0.0.1:8765
Senza modello (prova grafica): avvia_interfaccia.bat --demo

Contenuto
- app_lazarus\lazarus.py     BACKEND - logica dell'investigatore: modello, istruzioni, controllo di pertinenza
- interfaccia\backend\       BACKEND - server Python: ricerca nei documenti, indizi, storico, API per il browser
- interfaccia\frontend\      FRONTEND - pagine, stile e script del browser (chat, schede, bacheca)
- interfaccia\registro\      DATI - storico delle domande, elementi trovati, cache
- interfaccia\caricati\      DATI - documenti caricati a mano a ogni sessione (+ o pulsante cartella)
- lazzaro\diario_chat.jsonl  DATI - registro della squadra (domande e risposte)
Nessun documento e' caricato in automatico: all'inizio di ogni sessione carica la cartella dei dati (es. Dati_giorno_1).
Mappa completa (quale file fa cosa, funzione per funzione): ARCHITETTURA.md
Per cambiare modello: righe MODELLO / EMBEDDING in avvia_interfaccia.bat.
